# 🏠 Camps Crib

Camps Crib is a student-focused platform for finding PGs, flats, roommates, and tiffin services in one place.

## ✨ Features

- 🔐 User Authentication
  - Register and Login
  - JWT-based authentication

- 🏠 PG & Flat Listings
  - Browse accommodations
  - Post and manage listings

- 🍱 Tiffin Services
  - Find home-cooked meal providers

- 👥 Roommate Finder
  - Find compatible roommates

- 📊 Dashboard
  - Manage listings and requests

- 🏡 My Rentals
  - Track rental applications

- 👤 My Tenants
  - Manage tenants and rental requests

## 🔄 How It Works

User
↓
Register / Login
↓
Dashboard
↓
PG / Flats | Roommates | Tiffin
↓
Rentals / Tenants

## 🔐 Authentication

The application uses JWT-based authentication for secure user registration, login, and protected features.

## 🎯 Purpose

Camps Crib aims to simplify the process of finding accommodation and essential services for students while helping property owners manage their listings and tenants.
